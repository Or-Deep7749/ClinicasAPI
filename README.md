Sistema de Gestão Veterinária

Um sistema desenvolvido para gerenciar clínicas veterinárias, permitindo o controle de clínicas, tutores, pets e veterinários.

Tecnologias Utilizadas

- Front-end: Next.js (TypeScript), Tailwind CSS
- Back-end: Java, Spring Boot
- Banco de Dados: PostgreSQL

CRUD Completo

O sistema conta com operações de Criação, Leitura, Atualização e Exclusão para os seguintes módulos:
* Clínicas: Cadastro e gestão das unidades veterinárias.
* Tutores: Registro dos responsáveis pelos animais.
* Pets: Gestão dos animais vinculados aos tutores.
* Veterinários: Cadastro dos profissionais de saúde animal.

Como Executar o Projeto Localmente

Pré-requisitos
- Java JDK 17 ou superior
- Node.js (versão 18+)
- Maven
